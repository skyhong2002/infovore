# Dayflow card fonts

Figtree and Instrument Serif are bundled under the SIL Open Font License 1.1;
the accompanying OFL files retain each family's copyright and license notice.

Source: [Dayflow's fonts](https://github.com/JerryZLiu/Dayflow/tree/main/Dayflow/Dayflow/Fonts),
matching the native macOS app. `InstrumentSerif-Regular.ttf` is unmodified.
`Figtree-Regular.ttf` and `Figtree-Bold.ttf` are static instances of
`Figtree-VariableFont_wght.ttf` at weights 400 and 700, generated with FontTools
for Satori's static-font renderer. License texts are from the corresponding
[Google Fonts](https://github.com/google/fonts/tree/main/ofl) family directories.
