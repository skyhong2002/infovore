# infovore logo concepts

Five logo directions generated with the built-in `image_gen` tool on 2026-09-05.
Open `index.html` for the numbered comparison on a light image background.
The complete generation prompts are preserved in `prompts.json`.
These PNGs are concept proposals for selection, not final vector or favicon assets.

1. **資訊食客** — `01-information-eater.png`: 用吞入資訊的開口造型呼應 infovore 的名字。
2. **時間書籤** — `02-timeline-bookmark.png`: 把書籤與時間軸結合，代表保存生活中的文化足跡。
3. **匯流成 i** — `03-confluence-i.png`: 多股資訊匯聚成小寫 i，代表跨平台整合與個人身分。
4. **生活年輪** — `04-life-rings.png`: 以層層環繞的軌跡呈現逐年累積的生活紀錄。
5. **收藏生物** — `05-collector-creature.png`: 把收藏資訊的個性化成小生物，適合親切的品牌方向。
